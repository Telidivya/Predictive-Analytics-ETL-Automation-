# Payment Failure Intelligence System

An original, beginner-friendly portfolio project demonstrating payment transaction ETL, failure analysis, basic predictive modelling, SQL analytics, and a Power BI dashboard-ready dataset.

> **Data note:** `data/transactions.csv` is synthetic demo data generated for this project. It does not contain real customer or bank information. This project is an implementation starter, not a copy of a third-party repository.

## Features
- ETL pipeline: load, validate, clean, enrich, and export transaction data.
- Feature engineering: amount bands, transaction time bands, weekend flag, and encoded failure target.
- Predictive baseline: scikit-learn logistic regression to estimate failure probability.
- SQL: reusable KPI and operational-risk queries.
- Power BI: clean CSV outputs and a suggested dashboard layout.
- Unit tests for data preparation and KPI calculations.

## Power BI dashboard
1. Open Power BI Desktop and choose **Get data → Text/CSV**.
2. Import `cleaned_transactions.csv`, `daily_kpis.csv`, `payment_method_kpis.csv`, and `failure_reason_kpis.csv`.
3. Create relationships only if needed; the KPI exports can also be used as standalone visuals.
4. Suggested visuals:
   - Cards: Total Transactions, Failed Transactions, Failure Rate, Failed Amount.
   - Line chart: transaction date vs daily failure rate.
   - Bar chart: payment method vs failure rate.
   - Bar/donut: failure reason distribution.
   - Matrix: bank × payment method with transaction count and failure rate.
   - Slicers: date, region, bank, payment method, device type.

### Suggested DAX measures
```dax
Total Transactions = COUNTROWS(cleaned_transactions)
Failed Transactions =
CALCULATE(COUNTROWS(cleaned_transactions), cleaned_transactions[is_failed] = 1)
Failure Rate = DIVIDE([Failed Transactions], [Total Transactions], 0)
Failed Amount =
CALCULATE(SUM(cleaned_transactions[amount]), cleaned_transactions[is_failed] = 1)
Successful Amount =
CALCULATE(SUM(cleaned_transactions[amount]), cleaned_transactions[status] = "Successful")
```

## Alteryx workflow idea
Use **Input Data → Select → Data Cleansing → Formula → Filter → Summarize → Output Data**.
- Input: `data/transactions.csv`
- Clean/standardize date, amount, text columns.
- Formula: create `is_failed`, `amount_band`, `time_band`, and `is_weekend`.
- Summarize: count transactions and failed transactions by date/payment method/reason.
- Output: the same CSVs generated by the Python ETL.
